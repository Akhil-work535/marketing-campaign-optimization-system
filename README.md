# 📊 Marketing Campaign Optimization & Alert System

## 🚀 Overview
This project focuses on analyzing marketing campaign performance and building an automated system to identify underperforming campaigns based on conversion efficiency and cost effectiveness.

---

## 🎯 Business Problem
Marketing campaigns often generate high impressions and clicks but fail to convert users effectively, leading to inefficient ad spend and poor return on investment (ROI).

---

## 🧠 Solution Approach
- Designed a **data analysis pipeline** using Python and MySQL  
- Built a **SQL-based metrics layer** to evaluate campaign performance  
- Performed **funnel analysis** (Impressions → Clicks → Purchases)  
- Developed an **automated alert system** to detect poor-performing campaigns  

---

## 📊 Key Metrics
- **CTR (Click Through Rate)** = Clicks / Impressions  
- **Conversion Rate** = Purchases / Clicks  
- **CPA (Cost Per Acquisition)** = Cost / Purchases  

---

## ⚙️ Tech Stack
- Python (Pandas, MySQL Connector)
- MySQL (Data Storage & Querying)
- Power BI (Dashboard & Visualization)
- Task Scheduler (Automation)

---

## 🔄 Workflow
1. Data Cleaning & Preprocessing (Python)  
2. Data Storage in MySQL  
3. SQL-based Metric Calculation (CTR, Conversion, CPA)  
4. Identification of Underperforming Campaigns  
5. Automated Alert System using Python  
6. Visualization using Power BI  

---

## 📈 Key Insights
- Significant drop-off observed across the funnel (Impressions → Purchases)  
- Multiple campaigns have **low conversion rates (<5%)**  
- High CPA indicates inefficient marketing spend  
- Optimization should focus on improving conversion rather than increasing traffic  

---

## 🤖 Automation
A Python pipeline (`campaign_pipeline.py`) automatically:
- Fetches campaign data  
- Calculates performance metrics  
- Identifies underperforming campaigns  
- Updates alerts table in MySQL  

---

## 📊 Dashboard Features
- KPI Cards (CTR, Conversion Rate, CPA, Total Purchases)  
- Funnel Analysis Visualization  
- Campaign Performance Comparison  
- Alert Table for underperforming campaigns  


---

## 🔥 Outcome
Built an **end-to-end marketing analytics system** that not only analyzes campaign performance but also automates the detection of inefficient campaigns, enabling faster and data-driven decision-making.

---

## 💡 Key Learning
This project demonstrates how data analysis can move beyond reporting and be used to build **decision-support systems** that drive business impact.
